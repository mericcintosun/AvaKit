# AvaKit and the Team1 Mini Grant

Short answers to Team1's four questions, with the detail behind each.

1. **Can it run without the maintainer's machine?** Yes, in three ways, with daily proof on fresh machines. See [evidence.md](evidence.md).
2. **What is the remaining milestone, and what does it cost?** An approval-gated agent layer for Avalanche: x402 payments, ERC-8004 identity, spend limits, Builder Hub verification, a Team1 workshop kit and a public outcome ledger. USD 6,500, on Fuji. Everything already shipped costs nothing. See [milestone.md](milestone.md).
3. **How are signer, retry and dependency failures handled?** See [reliability.md](reliability.md).
4. **Who maintains it, and how is benefit measured?** I maintain it, eight hours a week for twelve months after the grant. Benefit is counted in builders other than me, with on-chain proof in a public ledger. See [milestone.md](milestone.md#who-maintains-it-and-after-the-grant).
